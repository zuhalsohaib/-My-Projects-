Zuhal Sohaib React Portfolio

This ZIP contains ONE project folder: zuhal-portfolio.

To run:
1. Extract the ZIP.
2. Open the zuhal-portfolio folder in VS Code (the folder containing package.json).
3. Open the terminal in that folder.
4. Run: npm install
5. Run: npm run dev

Images are in public/images.
Place your CV at public/files/Zuhal-CV.pdf for the CV download link.

Projects 3 and 4 currently use email links because their live project URLs were not supplied.
